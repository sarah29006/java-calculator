# Java Calculator
A simple calculator application built using **Java Swing**. This project was created as a beginner Java project to practice GUI development, event handling, and basic arithmetic operations.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Percentage
* Positive/negative toggle
* Decimal numbers
* Delete (DEL)
* Clear (AC)
* Basic error-free number input
* Simple graphical user interface

## Technologies Used

* Java
* Java Swing
* AWT

## Project Structure

Java-Calculator/
│
├── App.java
├── Calculator.java
└── README.md


### App.java

Contains the 'main' method and starts the calculator application.

### Calculator.java

Contains the calculator GUI, buttons, display, and calculation logic.

## How to Run

1. Make sure Java is installed on your computer.
2. Clone or download this repository.
3. Open the project in an IDE such as VS Code, IntelliJ IDEA, or Eclipse.
4. Compile and run 'App.java'.

Or using the terminal:

javac App.java Calculator.java
java App
